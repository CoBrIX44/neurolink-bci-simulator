Scientific Methodology & Backend Specifications

01 // Synthetic Electrophysiology

Signals mimic sensorimotor rhythm desynchronization (ERD/ERS). The 256 Hz time series superimposes target oscillatory sine components on low-frequency baseline drifts (0.2 Hz) and broad Gaussian noise.

02 // Zero-Phase Filtering

SciPy Butterworth bandpass (1–40 Hz, 4th order) operates forward and backward (filtfilt). This preserves waveform peaks at their exact physiological time indices without group delay distortion.

03 // Feature Normalization

Spectral powers in 1–12 Hz and 12–40 Hz bands are extracted and z-scored with StandardScaler before evaluation by Logistic Regression to mimic motor intention detection.
