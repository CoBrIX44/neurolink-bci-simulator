ELECTROPHYSIOLOGY ENGINEERING

Why 1–40 Hz Zero-Phase Butterworth Filtering?

In clinical and cognitive neuroscience, raw electroencephalography (EEG) voltages recorded at the scalp are severely corrupted by two physical artifacts:

  • Low-frequency drift (<1 Hz): Galvanic skin impedance shifts, sweating, and electrode movement cause high-amplitude baseline wanders that would distort machine learning normalization.
  • High-frequency noise (>40 Hz): Electromyographic (EMG) muscle activity from jaw clenching and 50/60 Hz electrical mains interference overpower faint microvolt-scale neural rhythms.

The 4th-order Butterworth band-pass filter isolates the sensorimotor rhythm range (1–40 Hz). Crucially, the simulator executes zero-phase offline processing via Scipy’s scipy.signal.filtfilt.

The Zero-Phase Tradeoff (filtfilt vs Online Real-Time)

filtfilt processes the input signal forward, reverses the array, and filters it again backward. This squares the filter magnitude response and completely cancels nonlinear phase shifts, ensuring peaks do not shift in time.

warning Constraint: Zero-phase requires the full signal buffer and cannot be performed instantaneously sample-by-sample in closed-loop live telemetry.
